# 1. بطاقة تعريف المنصة

| البند | التفاصيل |
|---|---|
| **الاسم التجاري** | مُثقّف — Muthaqaf AI Studio Copilot |
| **التعريف الرسمي** | منصة ذكاء اصطناعي احترافية لاستخبارات يوتيوب وصناعة المحتوى |
| **الجمهور المستهدف** | صنّاع محتوى يوتيوب (مبتدئين، قنوات نامية، قنوات احترافية، وكالات إدارة قنوات) |
| **اللغتان** | عربي / إنجليزي (واجهة كاملة ثنائية اللغة + لغة مخرجات قابلة للاختيار لأي لغة في العالم) |
| **المحرك الذهني** | Google Gemini (نصوص + تحليل صور + توليد صور) |
| **مصدر بيانات يوتيوب** | سكرابينج مباشر بدون مفتاح API + دعم اختياري لمفتاح YouTube Data API v3 |
| **نمط العمل** | استوديو محادثة ذكي (Copilot Chat) + 28 أداة متخصصة + أنظمة مساندة |
| **الهوية البصرية** | ثيم داكن فاخر «Liquid Botanical Glass» بلون نعناعي كهربائي `#00ff9d` |
| **التقدير** | تطبيق ويب أحادي الصفحة (SPA) + خادم Express مدمج |

## ما الذي يحلّه «مُثقّف»؟

صانع المحتوى العربي يواجه 6 معارك يومية، و«مُثقّف» بُني ليخوضها كلها نيابة عنه:

1. **معركة الأفكار** — ما الفيديو القادم الذي سينفجر؟ (→ بنك الأفكار، صائد الـ Outliers، تنبؤ التريند)
2. **معركة النقرة** — لماذا يمرّ المشاهد على مصغرتي دون نقر؟ (→ مولد المصغرات، محاكي A/B، هندسة نظرة العين)
3. **معركة الاحتفاظ** — لماذا يخرج المشاهد في الثانية 30؟ (→ كاتب السكريبتات، مقياس الدوبامين، خريطة الاحتباس)
4. **معركة الخوارزمية** — لماذا لا يقترح يوتيوب فيديوهاتي؟ (→ محاكي الخوارزمية، المجهر الزمني، صائد الردود)
5. **معركة المنافسة** — لماذا ينمو غيري وأنا أوقف؟ (→ استخبارات المنافسين، فحص القناة، العقل المدبر)
6. **معركة الدخل** — كيف أحوّل المشاهدات إلى مصادر دخل متعددة؟ (→ مختبر الأرباح، مولد الرعايات، المنتجات الرقمية)

# 2. الرؤية وفلسفة التصميم

## الرؤية

> أن يكون كل صانع محتوى عربي — في أي بلد وبأي ميزانية — يمتلك غرفة عمليات استخباراتية وإنتاجية بمستوى أكبر فرق تحليلات يوتيوب العالمية، بلغته، من متصفحه، خلال ثوانٍ.

## المبادئ الخمسة للتصميم

### 1. المحادثة أولاً (Conversation-First)
بدلاً من نماذج مليئة بالحقائق، يبدأ المستخدم محادثة طبيعية: «حلل قناتي»، «اكتب لي سكريبت عن...» — والمنصة تفهم النية وتختار الأداة الصحيحة تلقائياً.

### 2. ذكاء مزدوج (Hybrid Intelligence)
- **طبقة AI (Gemini):** للإبداع والتحليل العميق والسيكولوجيا والتوليد البصري.
- **طبقة خوارزميات محلية حتمية:** لحسابات الأرباح، الـ VPH، كشف الـ Outliers، أفضل الأوقات، احتمالية الفوز — أرقام سريعة وقابلة للتكرار لا تعتمد على عشوائية النموذج.

### 3. خصوصية المفاتيح (Bring Your Own Key)
كل مستخدم يمكنه إدخال مفاتيح Gemini و YouTube الخاصة به، تُحفظ مشفّرة في ملفه الشخصي على Firestore، ولا تُشارك مع أحد. وبدون أي مفتاح، تعمل المنصة عبر مفتاح الخادم العام.

### 4. الزجاج النباتي السائل (Liquid Botanical Glass)
هوية بصرية موقّعة: خلفية «خشب الأبنوس الأخضر العميق» `#050a09`، لون العلامة «نعناع نباتي كهربائي» `#00ff9d`، لوحات زجاجية بحواف مضيئة تتفاعل مع التمرير، خطوط Space Grotesk للاتيني وAlexandria للعربي وJetBrains Mono للأرقام التقنية.

### 5. كل فعل يُسجَّل (Accountable Actions)
كل استخدام لأداة يوثَّق في سجل النشاط (Firestore) — ليستطيع المستخدم تتبّع استهلاكه، ومراجعة تاريخه، وقياس عودته على الاستثمار من المنصة.

### 📜 ابدأ الأمر

**ابنِ منصة ويب باسم «مُثقّف | Muthaqaf AI Studio»** — مساعد ذكاء اصطناعي متكامل (Copilot) لصنّاع محتوى يوتيوب، يجمع في واجهة واحدة: غرفة محادثة ذكية، و28 أداة متخصصة، ونظام تحليل قنوات حيّ، ولوحة تحكم شخصية.

**التقنيات الإلزامية:**
- الواجهة: React 19 + TypeScript + Vite + Tailwind CSS، أيقونات lucide-react، رسوم بيانية Recharts، حركات Motion.
- التوجيه: react-router-dom بنمط HashRouter (لتوافق الاستضافة الثابتة).
- الخادم: Node.js + Express 5 يعمل كـ «بوابة موحّدة» — يقدّم الواجهة عبر Vite Middleware في التطوير وملفات static في الإنتاج.
- الذكاء الاصطناعي: SDK رسمي `@google/genai` من جهة الخادم.
- البيانات: Firebase Authentication (دخول Google) + Cloud Firestore + تخزين محلي localStorage للحالة الفورية.
- اللغة: دعم كامل ثنائي (عربي RTL / إنجليزي LTR) مع نظام ترجمة مركزي `TRANSLATIONS` ومُحدِّد لغة مخرجات مستقل لأي لغة عالمية.

**البنية المعمارية الإلزامية:**

```

├── index.tsx            نقطة الدخول + مزوّد اللغة + مزوّد المصادقة

├── server.ts            Express: /api/health + /api/gemini + /api/youtube/analyze-by-url
```

**أولّاً — ابنِ الخادم الخلفي بثلاث نقاط نهاية:**

1. `GET /api/health` — فحص حياة يرجع `{ status: "ok" }`.

2. `POST /api/gemini` — **بروكسي Gemini المؤمّن.** يستقبل `model, contents, systemInstruction, userApiKey`. ابنِ له سلسلة أمان ثلاثية للمفاتيح: (مفتاح المستخدم من الهيدر `x-gemini-api-key` أو جسم الطلب) ثم (متغير بيئة `GEMINI_API_KEY`) ثم (متغير `VITE_GEMINI_API_KEY`)، مع تنقية المفاتيح من علامات اقتباس وقيم وهمية (`undefined`, `YOUR_...`). نفّذ **سلسلةfallback للموديلات**: للنصوص جرّب بالترتيب: الموديل المطلوب ← `gemini-3.1-flash-lite` ← `gemini-flash-latest` ← `gemini-3.8-flash` ← `gemini-2.5-flash`؛ وللصور: المطلوب ← `gemini-3.1-flash-image` ← `gemini-3.1-flash-lite-image`. أعِد المحاولة مرتين لكل موديل عند أخطاء 503/429 (ضغط مرتفع) بانتظار 400ms، وانتقل للمفتاح التالي فوراً عند `API_KEY_INVALID`. أرجع دائماً النص النهائي + الاستجابة الكاملة.

3. `POST /api/youtube/analyze-by-url` — **محلل القنوات بدون مفتاح API.** استقبل `urlOrHandle` (رابط كامل أو @handle)، طبّعه (`normalizeYouTubeUrl`)، ثم اسحب من صفحات يوتيوب العامة: بيانات القناة (الاسم، الصورة، البانر، الوصف، البلد، تاريخ الانضمام، الروابط، عدد المشتركين والفيديوهات) + آخر 30 فيديو (عنوان، مشاهدات، وقت، مدة، مصغرة، معرف). مرّر الناتج فوراً إلى `performDeepChannelAiAudit` لتوليد تقرير استخباراتي كامل، وأرجع سجلاً موحّداً جاهزاً للتخزين.

**ثانياً — ابنِ محرك الذكاء الاصطناعي (geminiService) بعشرين+ دالة متخصصة،** لكل منها System Prompt مُحكم يعرّف شخصية الخبير ومخرجات منظمة: محادثة عامة واعية بالسياق، تدقيق قنوات، تحليل منافسين عميق، تدقيق أرباح، تحليل فيديو مفصّل، SEO متقدم، عناوين فيروسية، أفكار فيديو بمعايير إبداعية قابلة للضبط (مستوى إبداع/جمهور/صيغة)، خطة نمو مخصصة، تحليل جمهور نفسي، سكريبتات فيروسية، تحليل صور، توليد وتعديل صور (نمط «المصغرة السينمائية» 16:9)، تحليل Outliers، تحليل VPH، تحليل توقيت نشر فيديو، تحليل توقيت لمنطقة/بلد، توقّع عدّاد حي، تنبؤ تريندات بمخطط زخم، مفاهيم مصغرات، ومقارنة مصغرتي A/B سيكولوجية.

**ثالثاً — ابنِ طبقة الخوارزميات المحلية (algoService) التي لا تحتاج AI:** كشف النيش تلقائياً من العنوان والوصف والوسوم، مضاعف موسمية الربع الحالي، حاسبة أرباح معقدة (CPM لكل بلد × تفاعل × سياق)، تقدير أرباح سريع، توليد عناوين ذكية ونسخ بديلة، استخراج كلمات مفتاحية، **كاشف Outliers** (فيديو تجاوز متوسط القناة بعتبة قياسية)، تحليل توقيت الجمهور المتقدم، نمط النشر الأسبوعي، جدول نشر أسبوعي مقترح، أفكار فيديو احتياطية، و**حاسبة احتمالية الفوز** بين قناتين قبل المعركة.

**رابعاً — ابنِ نظام إدارة المفاتيح (apiKeyService):** مفتاح مستخدم يتفوّق على مفتاح الخادم، حفظ في Firestore ضمن ملف المستخدم، كاش في الذاكرة + localStorage، نشر فوري للتغييرات (pub-sub بسيط)، مؤشرات صحة المفاتيح في الواجهة، تسجيل استخدام لكل مفتاح، و**إعادة محاولة أسّية (Exponential Backoff)** لكل استدعاءات YouTube وGemini.

**خامساً — ابنِ محرك المهام (JobContext):** نظام تنفيذ غير متزامن موحّد لكل الأدوات الثقيلة (16 نوع مهمة: منافسون، مخطط، أفكار، outliers، جمهور، سكريبت، صور، SEO، تحليلات VPH/توقيت/عدّاد/أرباح/قناة/فيديو...) مع حالات (خامل/جاري/تم/خطأ)، تقدّم مرحلي بالعربية («2/3 توليد الصور...»)، منع التداخل، وتخزين النتائج في AppState المُداوم.

**سادساً — ابنِ نظام القنوات المرتبطة (ChannelContext + linkedChannelService):** المستخدم يضيف قناته برابط واحد فيُسحب كل شيء ويُحفظ محلياً وفي Firestore، ثم يستطيع ربط قنوات منافسين، وتشغيل «تدقيق عميق»، و«مقارنة وجهاً لوجه» بين قناتين مع حاسبة احتمالية الفوز.

**سابعاً — ابنِ الاستوديو الرئيسي (CopilotStudio):** شاشة موحّدة فيها: رأس بهويّة القناة الحالية ومنتقي القنوات، **رصيف المهارات (SkillDock)** أسفل الشاشة بأسلوب Dock تفاعلي يعرض 28 مهارة بأيقوناتها وتدرجاتها اللونية مصنّفة في 4 فئات (نمو/محتوى/سيو/تحليلات)، نافذة استعراض المهارات، منطقة محادثة ذكية باقتراحات سريعة، وكروت نتائج غنية (رسوم بيانية، بطاقات، أزرار تحميل PNG عبر html2canvas).

**ثامناً — ابنِ الأدوات الـ 28 حسب مواصفات القسم 9 من هذا الدليل حرفياً** (الاسم، الفئة، الوصف، الـ placeholder، والبرومبتات المقترحة لكل مهارة).

**تاسعاً — ابنِ الأنظمة المساندة:** محادثة عائمة (ChatAssistant) بذاكرة جلسة، مخطط نشر ذكي مع تصدير لمهام Google Tasks وإرسال بريد عبر Gmail API، مولد صور ثنائي النمط (مصغرة/حر) بأساليب فنية متعددة، أداة VPH (مشاهدات الساعة الأولى)، عدّاد مشتركين حي، محلل فيديو فردي، مختبر أرباح، تحليل توقيت فيديو، أفضل أوقات عالمية، صائد Outliers، سجلات نشاط كاملة، دليل المبدعين التعليمي، معرض برومبتات، ولوحة مستخدم (استخدام شهري، إنجازات، أهداف، أرقام قياسية، حالة الحساب، إدارة مفاتيح، تخصيص هوية بصرية للعلامة).

**عاشراً — طبّق الهوية البصرية بدقة:** خلفية `#050a09`، لون العلامة `#00ff9d` بتوهج `rgba(0,255,157,0.3)`، لوحات `.glass-panel` زجاجية (شفافية 70% + blur 8px + saturation 130%) ترتفع 2px عند التمرير، هالات خلفية شعاعية متحركة 30 ثانية، شرائح تمرير نعناعية متدرجة، خطوط: Space Grotesk / Outfit / Alexandria / JetBrains Mono، أرقام بخط المونو، وضع طباعة مخصص، وتحسين أداء عبر `content-visibility` و`backface-visibility`.

**وأخيراً — اجعله يحتفظ بكل شيء:** حالة الواجهة والنتائج في localStorage للاستمرارية الفورية، وسجل النشاط والقنوات المرتبطة والمفاتيح في Firestore للحساب الدائم، مع معالجة أخطاء Firestore برسائل عربية مفهومة لكل نوع عملية.

## 4.3 المزوّدات الأربعة (Providers)

1. **`AuthProvider`** — جلسة Firebase، حالة المستخدم، تحميل مفاتيحه تلقائياً عند الدخول.
2. **`AppStateProvider`** — حالة الواجهة المُداومة (نتائج الأدوات، الاختيارات) عبر `storageService`، مع خطاف `useSectionState` لحفظ أي قسم.
3. **`JobProvider`** — محرك تنفيذ المهام الـ 16 غير المتزامنة: طوابير، حالات، مراحل تقدم، إدارة أخطاء موحدة، وتخزين النتائج.
4. **`ChannelProvider`** — القناة النشطة + القنوات المرتبطة (خاصّة/منافسين) + عمليات الربط والتحديث والمقارنة.

# 8. رحلة المستخدم ودورة حياة المهمة

## الرحلة النموذجية

```
① الدخول        → تسجيل دخول Google (أو تصفح كزائر)
② ربط القناة    → لصق رابط القناة → سحب فوري لكل البيانات
③ الاكتشاف      → رصيف المهارات (Dock) أو المحادثة الحرة
④ التنفيذ       → أداة/بند برومبت → محرك المهام يعمل بمراحل مرحلية
⑤ النتيجة       → كارت غني (رسوم + بطاقات) قابل للتحميل PNG
⑥ التوثيق       → تسجيل تلقائي في سجل النشاط والإحصاءات
⑦ التحسين       → تدقيق عميق للقناة → خطة نمو → جدول نشر → تصدير للمهام
```

## دورة حياة المهمة في JobContext

```
idle → running (مرحلة 1/3، 2/3...) → done   [النتيجة تُخزَّن وتُعرض في Widget]
                                  ↘ error   [رسالة عربية + إمكانية إعادة]
```

منع تشغيل مهمتين ثقيلتين متوازيتين، حفظ النتائج عبر الجلسات، ولوحة تقدم نصية بالعربية («جاري توليد الصورة المصغرة بدقة 16:9 استوديو سينمائي...»).

# 10. الأنظمة المستقلة الإضافية

## 10.1 المساعد العائم — ChatAssistant
مساعد محادثة دائم في كل الشاشات، يفهم سياق الصفحة الحالية، يجيب بوعي كامل ببيانات قناتك المرتبطة، وينفذ أوامر ذكية: «حلل قناتي»، «اكتب لي سكريبت...»، «قارنني بـ...» — مع ذاكرة جلسة محفوظة وقابلية المسح.

## 10.2 المخطط الذكي — Planner
لوحة تخطيط نشر: أفكار معلقة على جدول زمني، توليد خطة محتوى بالـ AI، **تصدير مباشر إلى Google Tasks**، و**إرسال الخطة بالبريد عبر Gmail API** — المنصة الوحيدة التي ترسل عمرك للإيميل بنقرة.

## 10.3 مولد الصور — ImageGenerator
استوديو صور كامل بنمطين:
- **نمط مصغرة (Thumbnail):** يقفل الأبعاد على 16:9 ويثبّت برومبت «سينمائية يوتيوب» (إضاءة دراماتيكية، تشبع عالٍ، تركيز انفعالي).
- **نمط حر (Normal):** أي أبعاد (1:1، 9:16، 4:3...) وأي أسلوب فني من قائمة الأساليب.
- ميزات: رفع صورة وتعديلها، تحليل صورة بالـ AI، تنزيل مباشر، وحفظ السجل.

## 10.4 أداة VPH — VphTool
**مشاهدات الساعة الأولى (Views Per Hour):** ألصق رابط فيديو (أو قناتك تكشف أحدث فيديو) → حساب VPH الدقيق، مقارنة بالعمر، مكتبة نصائح موسعة `VPH_TIPS_EXPANDED`، وتحليل AI لـ«لماذا سرعتي كذا وما العلاج؟».

## 10.5 العدّاد الحي — LiveCounter
عدّاد مشتركين/مشاهدات لحظي لقناتك مع **توقع AI لمعدل النمو القادم** — مثالي للبث المباشر ولقطات الشاشة التحفيزية.

## 10.6 محلل الفيديو — VideoAnalyzer
تشريح أي فيديو برابط: SEO كامل (عنوان/وصف/وسوم/فصول)، VPH، مدة، أداء مقابل عمره، وتحليل AI عميق لنقاط القوة والضعف.

## 10.7 مختبر الأرباح — EarningsCalculator
الواجهة الحسابية لأداة 25: أدخل أرقاماً يدوياً أو اسحب قناة/فيديو، فتحصل على تفصيل AdSense + رعايات + توصيات مضاعفة، بخوارزمية `calculateComplexRevenue` المحلية (CPM لكل بلد × موسمية × تفاعل × نيش).

## 10.8 بصمة التوقيت — VideoTimingInsight
هل نشرت في التوقيت الميت؟ حلل أي فيديو منشور: وقت النشر مقابل جمهور القناة والبلد — واعرف كم مشاهدة «ضاعت» بسبب الساعة.

## 10.9 أفضل الأوقات العالمية — GlobalBestTimes
خريطة توقيت جماعية: أدخل بلدان جمهورك (مصر والسعودية والخليج وأوروبا...) فتحصل على أسبوع نشر كامل بالساعات المثلى لكل يوم وكل منطقة.

## 10.10 صائد الـ Outliers — Outliers
اكتشف فيديوهات قناتك (أو أي قناة) التي تجاوزت المتوسط بفارق صارخ — الخوارزمية المحلية تكشفها فوراً، والـ AI يفكك سرّها.

## 10.11 الغوص في الجمهور — AudienceDeepDive / AudienceInsights
نسختان متكاملتان لتحليل الجمهور: رسوم توزيع، سلوك توقيتي، جدول نشر أسبوعي مُولّد، وتشريح نفسي بالـ AI.

## 10.12 تحليل المنافسين — CompetitorAnalysis
قارن قناتك بأي منافس وجهاً لوجه: نمو، متوسطات، **احتمالية الفوز `calculateWinProbability`**، وفجوات محتوى قابلة للاستغلال — مع تحليل AI استخباراتي.

## 10.13 كاتب السكريبتات — ScriptWriter
ورشة سكريبت متعددة الأقسام (مقدمة/هوك/فقرات/خاتمة) بروابط حالة محفوظة — تكتب قسماً تلو قسم دون فقدان أي شيء، مع تحسين بالـ AI لكل قسم.

## 10.14 أدوات السيو — SeoTools
ورشة العناوين والأوصاف والوسوم الكاملة مع النسخ بنقرة والحفظ التلقائي.

## 10.15 مولد الأفكار — IdeaGenerator
ورشة أفكار بمعايير الضبط الثلاثة (إبداع/جمهور/صيغة) مع حفظ الأفكار في البنك المحلي.

## 10.16 دليل المبدعين — Guidelines
**مكتبة معرفية تعليمية كاملة** مدمجة في المنصة: منهجيات الأفكار، السكريبت، السيو، التخطيط، الصور، VPH، الأرباح، العدّاد الحي، المنافسين، الجمهور، الـ Outliers، التوقيت الفردي والعالمي، وسجل النشاط — مرجع «كيف تفكر صناعة المحتوى» وليس فقط «كيف تضغط زراً».

## 10.17 معرض البرومبتات — PromptsShowcase
مكتبة أوامر جاهزة احترافية لنسخ واستخدامها داخل المنصة أو في أي أداة AI خارجية.

# 11. نظام القنوات المرتبطة والتدقيق العميق

## 11.1 الربط برابط واحد — LinkedChannelsManagerModal
الصق رابط قناتك (أو @handle، أو رابط فيديو تُستخرج منه القناة) → السيرفر يسحب كل شيء: هوية، إحصاءات، وصف، بلد، روابط تواصل، وآخر 30 فيديو → يُخزَّن السجل محلياً وفي Firestore (`linkedChannelService`) مع طابع آخر تحديث.

## 11.2 منتقي القناة — ChannelHeaderSelector
شريط علوي دائم يعرض القناة النشطة (صورة + إحصاءات سريعة) وينقلك بين قنواتك بضغطة — كل الأدوات تعمل على القناة المختارة تلقائياً.

## 11.3 التدقيق العميق — ChannelDeepAuditModal
تشغيل `performDeepChannelAiAudit` على أي قناة مرتبطة: تقرير استخباراتي كامل (صحة، نمط نشر، جودة عناوين ومصغرات، ثغرات، خطة 90 يوماً) في مودال غني قابل للتصوير PNG.

## 11.4 المقارنة الوجهاً لوجه — ChannelComparisonModal
قناتك ضد أي منافس: مقارنة بصرية شاملة بكل المؤشرات + **حاسبة احتمالية الفوز** التي تقرر — بمؤشرات عديدة — أيهما سيفوز في معركة موضوع محدد.

# 13. دليل التشغيل والنشر

## 13.1 التطوير المحلي

```bash
npm install              # تثبيت الاعتماديات
cp .env.example .env.local   # ثم املأ المفاتيح
npm run dev              # تشغيل → http://localhost:3000
```

**متغيرات البيئة (.env.local):**

```ini
VITE_YOUTUBE_API_KEY=...   # اختياري: مفتاح YouTube Data API v3 (بدونه: سكرابينج تلقائي)
GEMINI_API_KEY=...         # مفتاح Gemini للخادم (المستخدمون يستطيعون إدخال مفاتيحهم من الواجهة)
```

## 13.2 الإنتاج

```bash
npm run build    # vite build + تجميع الخادم إلى dist/server.cjs
npm start        # تشغيل الخادم الإنتاجي على المنفذ 3000
```

في الإنتاج يقدّم Express ملفات `dist` الثابتة ويعالج كل المسارات كـ SPA، مع استمرار عمل نقاط `/api/*` كاملة.

## 13.3 فحوصات الجودة

```bash
npm run lint                 # فحص TypeScript الكامل (tsc --noEmit)
node scripts/checkModules.mjs    # زحف كامل لشجرة الموديولات والتأكد من عدم وجود مراجع CDN/مكسورة
node scripts/renderTest.mjs      # اختبار رندر حقيقي (jsdom + Vite SSR) يثبت رسم الواجهة وصفر أخطاء
```

## 13.4 مصفوفة المفاتيح

| السيناريو | Gemini | YouTube |
|---|---|---|
| مستخدم بلا أي مفتاح | مفتاح الخادم العام | سكرابينج بدون مفتاح |
| مستخدم بمفتاحه فقط | مفتاحه (أولوية أولى) | مفتاحه أو سكرابينج |
| خادم بلا مفتاح + مستخدم بلا مفتاح | الخطأ بإرشاد واضح لإدخال مفتاح | سكرابينج يعمل |

# 14. استكشاف الأخطاء وإصلاحها

| المشكلة | السبب المحتمل | الحل |
|---|---|---|
| صفحة بيضاء | إصدار قديم مُخبّأ (cache) من المتصفح | Hard Refresh: `Ctrl+Shift+R` |
| «مفتاح Gemini غير متوفر» | لا مفتاح خادم ولا مفتاح مستخدم | أضف مفتاحك من الإعدادات ← إدارة المفاتيح |
| تحليل قناة يرجع 0 فيديو | حجب شبكي لـ youtube.com من بيئة الخادم | جرّب من شبكة أخرى، أو استخدم مفتاح YouTube API |
| خطأ 429/503 في AI | ضغط على خدمة Gemini | النظام يعيد المحاولة تلقائياً عبر سلسلة الموديلات — انتظر قليلاً أو أدخل مفتاحك الخاص |
| تسجيل الدخول يفشل | نطاق Firebase غير مهيأ | راجع `firebase-applet-config.json` وتفعيل مزوّد Google |
| التوقيت العالمي غير دقيق | بلد غير موجود في `COUNTRY_TIMEZONES` | أضفه إلى `constants.ts` |
